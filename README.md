# Portfolio

A Vite + React + Tailwind setup wrapping your `Portfolio` component.

## Run locally

```bash
npm install
npm run dev
```

Then open the URL Vite prints (usually http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```

## Notes

- Your component lives at `src/Portfolio.jsx` — edit it directly, changes hot-reload.
- Update `CV_URL` and other constants at the top of `Portfolio.jsx` before deploying.
- Tailwind is configured to scan `index.html` and everything in `src/`, so any Tailwind classes you use will work out of the box.
